## Quick Summary

- Debugging tools show code behavior.
- Console methods display messages.
- Breakpoints pause execution.
- Errors provide useful details.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| Console | Shows logs and errors. |
| Breakpoints | Pause code. |
| Error Object | Provides name and message. |
| Debugger | Helps inspect running code. |

---

## Simple Example

<details open>
<summary><strong>💻 Click to Hide/Show Code Example</strong></summary>
<br>

```javascript
debugger;
```
</details>

---

## Remember

- Use tools to inspect code.
- Console methods show output.
- Breakpoints pause execution.
- The `debugger` statement can stop code.
