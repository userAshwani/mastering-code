## Quick Summary

- Error messages help identify problems.
- Line numbers can show where errors happen.
- The console displays many errors.
- Fix one problem at a time.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| Error Message | Explains the issue. |
| Line Number | Shows where it happened. |
| Console | Displays errors. |
| Stack | Can show call path. |

## Remember

- Read error messages carefully.
- Check the reported line.
- Use the console for details.
- Fix and test again.
