**JavaScript error handling uses try, catch, throw, and finally.**

</div>

---

## Quick Summary

- `try` tests a block of code.
- `catch` handles errors.
- `throw` creates a custom error.
- `finally` runs after try and catch.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| `try` | Code to test. |
| `catch` | Handles errors. |
| `throw` | Creates an error. |
| `finally` | Runs after handling. |

---

## Simple Example

<details open>
<summary><strong>💻 Click to Hide/Show Code Example</strong></summary>
<br>

```javascript
try {
  throw "Too big";
} catch (err) {
  console.log(err);
}
```
</details>

---

## Remember

- Use `try...catch` for error handling.
- Use `throw` for custom errors.
- `finally` always runs after try/catch.
- Errors can be handled.
