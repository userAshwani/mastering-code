## Quick Summary

- The console shows JavaScript output.
- `console.log()` writes messages.
- It helps inspect variable values.
- It is useful for quick checks.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| Console | Debug output area. |
| `console.log()` | Prints values. |
| Message | Text shown in console. |
| Value Check | Shows variable contents. |

## Remember

- Use console messages for quick debugging.
- Log variables to inspect values.
- The console is part of browser tools.
- Remove extra logs when finished.
