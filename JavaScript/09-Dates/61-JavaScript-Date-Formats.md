---

## Quick Summary

- ISO dates use `YYYY-MM-DD`.
- Short dates can use formats like `MM/DD/YYYY`.
- Long dates can use month names.
- ISO format is generally the preferred date format.

---

## Key Points

| Format | Example |
| :--- | :--- |
| ISO Date | `2015-03-25` |
| Short Date | `03/25/2015` |
| Long Date | `Mar 25 2015` |
| Full Date | `Wednesday March 25 2015` |

</details>

---

## Remember

- ISO dates are written year first.
- Date strings can be converted to Date objects.
- Browser behavior can vary for some date formats.
- Month and day order matters in short dates.
