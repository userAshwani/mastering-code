**Date set methods change parts of a Date object.**

</div>

---

## Quick Summary

- Set methods update date values.
- You can set year, month, day, hour, minute, second, and millisecond.
- `setMonth()` uses month numbers from `0` to `11`.
- Set methods change the original Date object.

---

## Key Points

| Method | Changes |
| :--- | :--- |
| `setFullYear()` | Year. |
| `setMonth()` | Month. |
| `setDate()` | Day of the month. |
| `setHours()` | Hour. |
| `setMinutes()` | Minutes. |

---

## Simple Example

<details open>
<summary><strong>💻 Click to Hide/Show Code Example</strong></summary>
<br>

```javascript
const d = new Date();
d.setFullYear(2020);
```
</details>

---

## Remember

- Set methods modify existing Date objects.
- Months start from `0`.
- Date values can be changed after creation.
- UTC set methods are also available.
