**JavaScript Date objects store and work with dates and times.**

</div>

---

## Quick Summary

- Date objects are created with `new Date()`.
- Dates include year, month, day, hours, minutes, seconds, and milliseconds.
- JavaScript counts months from `0` to `11`.
- Date objects are static after creation unless changed with methods.

---

## Key Points

| Syntax | Meaning |
| :--- | :--- |
| `new Date()` | Creates a date with the current date and time. |
| `new Date(date string)` | Creates a date from a date string. |
| `new Date(year, month, ...)` | Creates a date from date numbers. |
| Months | January is `0`, December is `11`. |

## Remember

- Date objects are created with the `Date` constructor.
- Month numbers start at `0`.
- JavaScript stores dates as milliseconds.
- Date objects can be shown as strings.
