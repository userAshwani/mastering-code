---

## Quick Summary

- Date objects include many built-in methods.
- Methods can get date parts.
- Methods can set date parts.
- Methods can convert dates to strings.

---

## Key Points

| Method Type | Examples |
| :--- | :--- |
| Create | `Date()`, `new Date()` |
| Get | `getFullYear()`, `getMonth()`, `getDate()` |
| Set | `setFullYear()`, `setMonth()`, `setDate()` |
| Convert | `toString()`, `toDateString()`, `toISOString()` |

## Remember

- Date methods work with Date objects.
- Get methods read date values.
- Set methods change date values.
- Conversion methods return date strings.
