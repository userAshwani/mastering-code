## Quick Summary

- Functions in JavaScript are objects possessing built-in properties and methods.
- length property returns the number of expected parameters declared in the definition.
- name property returns the string name of the function.
- toString() returns a string representing the source code of the function.
- call(), apply(), and bind() control this binding and invocation.

---

## Key Points

| Feature / Method | Description |
| :--- | :--- |
| **fn.length** | Number of parameters declared in function definition. |
| **fn.name** | String name of the function. |
| **fn.toString()** | Returns string representation of function source code. |
| **fn.bind()** | Returns new function bound to specified this object. |

## Remember

- Function length counts declared parameters excluding rest parameters.
- Anonymous functions assigned to variables inherit variable name as fn.name.
- Functions inherit from Function.prototype and Object.prototype.
- Functions can have custom properties added to them like any object.
