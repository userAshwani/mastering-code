**A function expression stores a function inside a variable.**

</div>

---

## Quick Summary

- A function can be stored in a variable.
- Function expressions can be anonymous.
- The variable can be used as a function.
- Function expressions are not hoisted like function declarations.

---

## Key Points

| Item | Simple Meaning |
| :--- | :--- |
| Function expression | A function assigned to a variable. |
| Anonymous function | A function without a name. |
| Variable call | Call the function using the variable name. |
| Semicolon | Often used after a function expression. |

---

## Simple Example

<details open>
<summary><strong>💻 Click to Hide/Show Code Example</strong></summary>
<br>

```javascript
const x = function (a, b) {
  return a * b;
};

let z = x(4, 3);
console.log(z);
```
</details>

---

## Remember

- Function expressions can be stored in variables.
- Anonymous functions are common in expressions.
- Use the variable name to call the function.
- Function expressions are useful when functions are treated as values.
