## Quick Summary

- Functions in JavaScript are first-class objects that can be assigned to variables.
- Functions can be passed as arguments to other functions or returned as values.
- Higher-order functions accept functions as parameters or return new functions.
- Pure functions produce identical outputs for given inputs without side effects.
- Function expressions can be anonymous or named.

---

## Key Points

| Feature / Method | Description |
| :--- | :--- |
| **First-Class Functions** | Functions treated like any other variable value. |
| **Higher-Order Functions** | Functions that take or return other functions. |
| **Pure Functions** | Functions with no side effects and consistent return values. |
| **Anonymous Functions** | Functions defined without an explicit name. |

## Remember

- JavaScript functions can store properties and methods like regular objects.
- Passing functions as arguments forms the basis of callback patterns.
- Higher-order functions enable declarative programming patterns (map/filter/reduce).
- Keeping functions pure simplifies code testing and debugging.
