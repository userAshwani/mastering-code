## Quick Summary

- Function quizzes test function basics.
- Questions may cover declarations and calls.
- Questions may cover parameters and return values.
- Quizzes help review function syntax.

---

## Key Points

| Quiz Area | Simple Meaning |
| :--- | :--- |
| Function declaration | Writing a function. |
| Function call | Running a function. |
| Parameters | Values received by a function. |
| Return value | Value sent back from a function. |
