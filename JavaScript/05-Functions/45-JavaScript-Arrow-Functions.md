---

## Quick Summary

- Arrow functions were introduced in ES6.
- They use the `=>` syntax.
- They can make function syntax shorter.
- `return` can be skipped for simple one-line functions.
- Arrow functions do not have their own `this`.

---

## Key Points

| Syntax | Simple Meaning |
| :--- | :--- |
| `=>` | Arrow function symbol. |
| `(a, b)` | Function parameters. |
| `a * b` | Returned expression. |
| `{ ... }` | Function body for multiple statements. |

  return "Hello World!";

</details>

<details open>
<summary><strong>💻 Click to Hide/Show Code Example</strong></summary>

```javascript
let hello = () => "Hello World!";
```
</details>

---

## Remember

- Arrow functions are shorter than regular functions.
- Use `=>` to write an arrow function.
- Parentheses can be skipped for one parameter.
- Arrow functions handle `this` differently.
