## Quick Summary

- Temporal is part of modern JavaScript date-time work.
- It defines standard object types.
- It improves date and time handling.
- Support can depend on the JavaScript environment.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| Standard API | Defines Temporal objects and methods. |
| Environment | Support can vary. |
| Polyfill | Can provide support where needed. |
| Goal | Better date and time handling. |
