## Quick Summary

- Temporal is a new date and time API.
- It is designed to be easier than Date.
- It supports time zones and calendars.
- It separates different date and time concepts.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| Date and Time | Use Temporal objects for clear date-time values. |
| Time Zone | Use zoned types when the zone matters. |
| Calendar | Calendar information can be part of Temporal values. |
| Precision | Temporal supports precise time handling. |

## Remember

- Temporal is more structured than Date.
- Choose plain values for simple dates or times.
- Choose zoned values when time zones matter.
- Temporal objects make intent clearer.
