**The typeof operator returns the type of a JavaScript value.**

</div>

---

## Quick Summary

- `typeof` returns a type string.
- It can check strings and numbers.
- It can check booleans and functions.
- Some results have special behavior.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| `typeof "John"` | `string` |
| `typeof 3.14` | `number` |
| `typeof true` | `boolean` |
| `typeof function(){}` | `function` |

## Remember

- Use `typeof` to inspect values.
- The result is text.
- Arrays return `object`.
- Null also returns `object`.
