---

## Quick Summary

- `NaN` represents an invalid number result.
- It is a JavaScript number value.
- Invalid math can produce `NaN`.
- `isNaN()` can test for NaN.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| `NaN` | Not a Number. |
| Type | Number. |
| `isNaN()` | Checks for NaN. |
| Invalid Math | Can produce NaN. |

## Remember

- NaN means a number operation failed.
- NaN is still type number.
- Use `isNaN()` to test values.
- Numeric strings can still work in math.
