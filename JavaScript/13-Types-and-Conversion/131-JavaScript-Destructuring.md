**Destructuring unpacks array or object values into variables.**

</div>

---

## Quick Summary

- Destructuring assigns values from arrays.
- Destructuring assigns properties from objects.
- It can make assignments shorter.
- Names can match object property names.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| Array Destructuring | Unpacks by position. |
| Object Destructuring | Unpacks by property name. |
| Assignment | Creates variables from values. |
| Rest | Can collect remaining values. |

---

## Simple Example

<details open>
<summary><strong>💻 Click to Hide/Show Code Example</strong></summary>
<br>

```javascript
const person = { firstName: "John", lastName: "Doe" };
let { firstName, lastName } = person;
```
</details>

---

## Remember

- Use destructuring to unpack data.
- Arrays unpack by order.
- Objects unpack by property name.
- It can reduce repeated access code.
