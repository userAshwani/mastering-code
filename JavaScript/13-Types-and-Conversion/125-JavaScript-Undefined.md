## Quick Summary

- A variable without a value is `undefined`.
- Functions can return `undefined`.
- Object properties can be `undefined`.
- `undefined` is a JavaScript value.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| Declared Variable | Value before assignment. |
| Missing Property | Returns `undefined`. |
| Function Without Return | Returns `undefined`. |
| Type | `typeof undefined` is `undefined`. |

## Remember

- Undefined means no assigned value.
- Missing properties can return undefined.
- It is different from an empty string.
- Assign a value when needed.
