## Quick Summary

- JavaScript can convert types automatically.
- String and number operations can trigger conversion.
- Comparisons can trigger conversion.
- Automatic conversion can affect results.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| Coercion | Automatic type conversion. |
| `+` | Can join strings. |
| Numeric Operators | Can convert strings to numbers. |
| Comparison | Can convert values before comparing. |

## Remember

- Coercion happens automatically.
- The `+` operator can create strings.
- Math operators often convert to numbers.
- Know value types before operations.
