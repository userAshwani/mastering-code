</div>

---

## Quick Summary

- Primitive values are not objects.
- String, number, boolean, null, undefined, symbol, and bigint are primitive.
- Primitive values hold a single value.
- Primitive values are immutable.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| String | Text. |
| Number | Numeric value. |
| Boolean | True or false. |
| Undefined | Variable without a value. |
