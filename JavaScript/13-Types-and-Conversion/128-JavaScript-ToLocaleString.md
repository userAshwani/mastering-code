**toLocaleString converts values to locale-sensitive strings.**

</div>

---

## Quick Summary

- `toLocaleString()` returns a string.
- It can format numbers.
- It can format dates.
- Output can depend on locale settings.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| Number | Locale formatted text. |
| Date | Locale formatted date text. |
| Locale | Controls output style. |
| Options | Controls formatting details. |

---

## Simple Example

<details open>
<summary><strong>💻 Click to Hide/Show Code Example</strong></summary>
<br>

```javascript
let num = 123456.789;
let text = num.toLocaleString();
```
</details>

---

## Remember

- Use it for locale-aware output.
- Dates and numbers can be formatted.
- Output can vary by locale.
- Options can customize formatting.
