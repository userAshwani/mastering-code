## Quick Summary

- JavaScript has primitive and object data types.
- Strings store text.
- Numbers store numeric values.
- Objects store collections of data.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| String | Text value. |
| Number | Numeric value. |
| Boolean | `true` or `false`. |
| Object | Collection of properties. |

## Remember

- Data types describe value kinds.
- Variables can hold any type.
- Primitive values are simple.
- Objects can hold multiple values.
