---

## Quick Summary

- `toString()` returns a string.
- Numbers can become strings.
- Arrays can become comma-separated strings.
- Objects can have toString behavior.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| Number | Converts to text. |
| Array | Converts values to string. |
| Method | Called with parentheses. |
| Result | String value. |

---

## Simple Example

<details open>
<summary><strong>💻 Click to Hide/Show Code Example</strong></summary>
<br>

```javascript
let x = 123;
let text = x.toString();
```
</details>

---

## Remember

- Use `toString()` for string conversion.
- The result is text.
- Arrays become comma-separated text.
- Conversion output depends on value type.
