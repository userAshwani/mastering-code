---

## Quick Summary

- Symbols are primitive values.
- Every Symbol is unique.
- Symbols can be object property keys.
- Symbols are created with `Symbol()`.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| `Symbol()` | Creates a symbol. |
| Unique | Each symbol is different. |
| Primitive | Symbol is not an object. |
| Property Key | Can be used in objects. |

---

## Simple Example

<details open>
<summary><strong>💻 Click to Hide/Show Code Example</strong></summary>

```javascript
const id = Symbol("id");
```
</details>

---

## Remember

- Symbols are always unique.
- Use `Symbol()` to create one.
- Symbols can label object properties.
- Symbols are primitive values.
