---

## Quick Summary

- Values can be converted to strings.
- Values can be converted to numbers.
- Values can be converted to booleans.
- Conversion can be explicit or automatic.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| `String()` | Converts to string. |
| `Number()` | Converts to number. |
| `Boolean()` | Converts to boolean. |
| `toString()` | Converts to string. |

## Remember

- Use conversion functions for clear code.
- `Number()` converts numeric text.
- `String()` creates text.
- `Boolean()` creates true or false.
