## Quick Summary

- Objects store named values.
- Arrays are special objects.
- Functions are objects.
- Objects can contain properties and methods.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| Object | Named properties. |
| Array | Ordered list. |
| Function | Callable object. |
| Date | Date object. |

## Remember

- Objects can hold many values.
- Properties use names.
- Methods are functions stored in objects.
- Arrays are a type of object.
