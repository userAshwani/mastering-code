## Quick Summary

- Reserved words cannot be used as variable names.
- They are part of JavaScript syntax.
- Examples include `let`, `class`, and `return`.
- Using them incorrectly causes errors.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| `let` | Variable declaration keyword. |
| `class` | Class declaration keyword. |
| `return` | Function return keyword. |
| `if` | Conditional keyword. |

## Remember

- Do not use reserved words as identifiers.
- Choose clear custom names.
- Reserved words have language meaning.
- Invalid names can cause syntax errors.
