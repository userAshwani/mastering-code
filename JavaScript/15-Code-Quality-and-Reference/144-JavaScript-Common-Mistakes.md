## Quick Summary

- Assignment and comparison can be confused.
- Loose comparison can surprise beginners.
- Missing syntax can break code.
- String and number mixing can change results.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| `=` | Assignment. |
| `==` | Loose comparison. |
| `===` | Strict comparison. |
| `+` | Adds numbers or joins strings. |

## Remember

- Do not confuse assignment with comparison.
- Know when strings are joined.
- Check types before comparing.
- Use careful syntax.
