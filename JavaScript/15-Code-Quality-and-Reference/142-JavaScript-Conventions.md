## Quick Summary

- Conventions improve readability.
- Use consistent names.
- Use consistent spacing.
- Keep code organized.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |

| Spaces | Keep spacing consistent. |
| Lines | Avoid overly long lines. |
| Style | Follow one format. |
