## Quick Summary

- Reduce unnecessary work.
- Avoid repeated DOM access when possible.
- Keep loops efficient.
- Use local variables for repeated values.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| DOM Access | Can be slow when repeated. |
| Loops | Keep repeated work small. |
| Variables | Store repeated values. |
| Code Size | Smaller code can load faster. |
