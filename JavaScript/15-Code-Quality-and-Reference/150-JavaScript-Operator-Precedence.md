**Operator precedence decides which operations run first.**

</div>

---

## Quick Summary

- Some operators run before others.
- Parentheses can control order.
- Multiplication runs before addition.
- Assignment usually happens after expressions are evaluated.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| Parentheses | Highest control over order. |
| Multiplication | Before addition. |
| Addition | After multiplication. |
| Assignment | Stores final value. |
