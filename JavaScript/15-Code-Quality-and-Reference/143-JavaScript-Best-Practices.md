## Quick Summary

- Declare variables before use.
- Avoid global variables when possible.
- Use strict comparisons.
- Keep code simple.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| Declare Variables | Avoid accidental globals. |
| Strict Comparison | Use `===` when suitable. |
| Simple Code | Easier to debug. |
| Avoid Globals | Reduces name conflicts. |

## Remember

- Declare variables clearly.
- Use strict equality for type and value.
- Avoid unnecessary globals.
- Keep statements readable.
