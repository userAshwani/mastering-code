**Statements tell JavaScript what actions to perform.**

</div>

---

## Quick Summary

- Statements are instructions.
- Statements can declare variables.
- Statements can control flow.
- Statements often end with semicolons.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| `let` | Declares a variable. |
| `if` | Runs code conditionally. |
| `for` | Creates a loop. |
| `return` | Returns from a function. |

---

## Simple Example

<details open>
<summary><strong>💻 Click to Hide/Show Code Example</strong></summary>
<br>

```javascript
let x = 5;
if (x > 0) {
  console.log(x);
}
```
</details>

---

## Remember

- Statements perform actions.
- Use control statements for decisions and loops.
- Declarations create variables.
- Semicolons separate statements.
