---

## Quick Summary

- JSON data is written as key: value pairs inside curly braces {}.
- Keys must always be strings enclosed in double quotes.
- Values can be string, number, object, array, true, false, or null.
- Multiple key-value pairs are separated by commas.
- JSON arrays are ordered lists enclosed in square brackets [].

---

## Key Points

| Feature / Method | Description |
| :--- | :--- |
| **String Values** | Must be wrapped in double quotes: "value". |
| **Number Values** | Written without quotes: 42 or 3.14. |
| **Boolean Values** | Written as true or false (lowercase). |
| **Null Values** | Written as null (lowercase). |

## Remember

- Trailing commas after the last item are not allowed in JSON.
- Comments are not supported in JSON format.
- JSON object keys are always strings; JavaScript object keys can be identifiers.
- Undefined and functions are not valid JSON values.
