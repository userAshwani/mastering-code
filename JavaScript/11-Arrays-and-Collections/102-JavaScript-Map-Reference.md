## Quick Summary

- Map has a `size` property.
- Map methods manage key-value pairs.
- Map entries can be looped.
- Map keys can be any data type.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| Property | `size` |
| Add/Read | `set()`, `get()` |
| Remove | `delete()`, `clear()` |
| Loop | `forEach()`, `entries()`, `keys()`, `values()` |

---

## Simple Example

<details open>

`javascript
const fruits = new Map();
fruits.set("apples", 500);
`
</details>

---

## Remember

- Use `size` for entry count.
- Use `set()` and `get()` for values.
- Use `keys()` for all keys.
- Use `values()` for all values.
