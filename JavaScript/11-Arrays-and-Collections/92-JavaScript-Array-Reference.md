## Quick Summary

- Arrays have properties and methods.
- `length` gives array size.
- Methods can add, remove, search, sort, and iterate.
- Reference pages help find exact method behavior.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| Property | `length` |
| Add/Remove | `push()`, `pop()`, `shift()`, `unshift()` |
| Search | `indexOf()`, `includes()`, `find()` |
| Iterate | `forEach()`, `map()`, `filter()` |

## Remember

- Use `length` for array size.
- Array methods cover common list tasks.
- Some methods change the array.
- Some methods return new arrays or values.
