## Quick Summary

- A Map holds key-value pairs.
- Keys can be any data type.
- Maps remember original key order.
- Maps are created with `new Map()`.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| Map | Collection of key-value pairs. |
| Key | Identifies a value. |
| Value | Stored data for a key. |
| `size` | Counts Map elements. |

---

## Simple Example

<details open>
<summary><strong>💻 Click to Hide/Show Code Example</strong></summary>
<br>

`javascript
const fruits = new Map([
  ["apples", 500],
  ["bananas", 300]
]);
`
</details>

---

## Remember

- Maps store pairs of keys and values.
- Any value can be used as a key.
- Use `size` to count entries.
- Maps keep insertion order.
