## Quick Summary

- Set logic works with relationships between sets.
- Union combines values.
- Intersection keeps shared values.
- Difference keeps values not found in another set.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| Union | Combines values from sets. |
| Intersection | Keeps common values. |
| Difference | Keeps values missing from another set. |
| Relationship Checks | Test how sets relate. |

## Remember

- Use union to combine sets.
- Use intersection to find shared values.
- Use difference to find missing values.
- Set logic is useful for unique collections.
