## Quick Summary

- Set has a `size` property.
- Set methods manage unique values.
- Set methods can loop values.
- Set logic methods compare sets.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| Property | `size` |
| Add/Delete | `add()`, `delete()`, `clear()` |
| Check | `has()` |
| Loop | `forEach()`, `values()` |

---

## Simple Example

<details open>
<summary><strong>💻 Click to Hide/Show Code Example</strong></summary>
<br>

`javascript
const letters = new Set(["a", "b", "c"]);
let size = letters.size;
`
</details>

---

## Remember

- Use `size` to count Set values.
- Use `has()` to check values.
- Use `clear()` to empty a Set.
- Set values are unique.
