**Array search methods find values or positions inside arrays.**

</div>

---

## Quick Summary

- Search methods locate array items.
- `indexOf()` returns the first matching index.
- `lastIndexOf()` searches from the end.
- `includes()` checks if a value exists.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| `indexOf()` | Finds the first index of a value. |
| `lastIndexOf()` | Finds the last index of a value. |
| `includes()` | Checks whether a value exists. |
| `find()` | Returns the first matching element. |

---

---

## Remember

- Search methods help find array content.
- Indexes start at `0`.
- `includes()` returns true or false.
- `find()` uses a test function.
