## Quick Summary

- Arrays can be created with `new Array()`.
- Arrays can also be created with `[]`.
- Array literals are easier to read.
- A single number in `new Array()` creates empty slots.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| `[]` | Creates an array literal. |
| `new Array()` | Creates an array object. |
| Single Number | Creates array length, not one value. |
| Multiple Values | Creates array with those values. |

## Remember

- Prefer array literals for simple arrays.
- Be careful with `new Array(40)`.
- Both methods create arrays.
- Array literals are shorter.
