**A Set stores unique values in JavaScript.**

</div>

---

## Quick Summary

- A Set is a collection of unique values.
- Each value can occur only once.
- Sets can hold any value type.
- Sets are created with `new Set()`.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| Set | Collection of unique values. |
| `new Set()` | Creates a Set. |
| `add()` | Adds a value. |
| `size` | Returns number of values. |

---

## Simple Example

<details open>
<summary><strong>💻 Click to Hide/Show Code Example</strong></summary>
<br>

`javascript
const letters = new Set(["a", "b", "c"]);
`
</details>

---

## Remember

- Sets store unique values.
- Duplicate values are ignored.
- Use `size` to count Set values.
- Use `add()` to add values.
