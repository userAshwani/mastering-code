## Quick Summary

- Set methods manage Set values.
- `add()` adds a value.
- `delete()` removes a value.
- `has()` checks if a value exists.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| `add()` | Adds a value. |
| `delete()` | Removes a value. |
| `has()` | Checks for a value. |
| `forEach()` | Loops through values. |

---

---

## Remember

- Use `add()` to insert values.
- Use `delete()` to remove values.
- Use `has()` for true/false checks.
- Use `size` to count values.
