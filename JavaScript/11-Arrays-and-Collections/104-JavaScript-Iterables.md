**Iterables are objects that can be looped with `for...of`.**

</div>

---

## Quick Summary

- Iterables can be looped one value at a time.
- Strings are iterable.
- Arrays are iterable.
- Maps and Sets are iterable.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| Iterable | Can be used in `for...of`. |
| String | Iterable characters. |
| Array | Iterable elements. |
| Map/Set | Iterable collection values. |

---

## Simple Example

<details open>
<summary><strong>💻 Click to Hide/Show Code Example</strong></summary>
<br>

`javascript
const name = "JavaScript";
for (const x of name) {
  console.log(x);
}
`
</details>

---

## Remember

- Iterables work with `for...of`.
- Strings loop by characters.
- Arrays loop by elements.
- Sets and Maps are iterable collections.
