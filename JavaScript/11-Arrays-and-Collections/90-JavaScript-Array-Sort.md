## Quick Summary

- `sort()` sorts array values.
- `reverse()` reverses array order.
- By default, `sort()` sorts values as strings.
- Number sorting needs a compare function.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| `sort()` | Sorts array elements. |
| `reverse()` | Reverses array order. |
| Compare Function | Controls number sorting. |
| Random Sort | Can use a compare function pattern. |

---

## Simple Example

`javascript
const fruits = ["Banana", "Orange", "Apple", "Mango"];
fruits.sort();
`
</details>

---

## Remember

- Default sorting is alphabetical/string based.
- Use a compare function for numbers.
- `reverse()` changes item order.
- Sorting changes the array.
