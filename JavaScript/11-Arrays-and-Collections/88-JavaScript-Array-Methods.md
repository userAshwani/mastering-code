## Quick Summary

- Array methods work with array items.
- Some methods change the original array.
- Some methods return new values.
- Common methods include `push()`, `pop()`, `join()`, and `splice()`.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| `push()` | Adds an item to the end. |
| `pop()` | Removes the last item. |
| `join()` | Joins array values into a string. |
| `splice()` | Adds or removes array items. |

## Remember

- Use methods to manage array values.
- Check whether a method changes the original array.
- `push()` adds to the end.
- `pop()` removes from the end.
