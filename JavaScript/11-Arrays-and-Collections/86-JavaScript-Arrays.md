## Quick Summary

- Arrays hold more than one value.
- Array values are accessed by index.
- Indexes start at `0`.
- Arrays are special objects.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| Array | Stores a list of values. |
| Index | Position of an item in the array. |
| `length` | Returns the number of array elements. |
| Element | One value inside an array. |

---

## Simple Example

<details open>
<summary><strong>💻 Click to Hide/Show Code Example</strong></summary>
<br>

`javascript
const cars = ["Saab", "Volvo", "BMW"];
let car = cars[0];
`
</details>

---

## Remember

- Use arrays for lists of values.
- The first item is index `0`.
- Use `length` to count items.
- Arrays can store different value types.
