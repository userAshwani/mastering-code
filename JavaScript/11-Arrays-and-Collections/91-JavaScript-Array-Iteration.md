## Quick Summary

- Iteration methods loop over arrays.
- `forEach()` runs a function for each item.
- `map()` creates a new array.
- `filter()` creates a new array with matching items.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| `forEach()` | Runs code for each item. |
| `map()` | Creates a new array from results. |
| `filter()` | Keeps matching items. |
| `reduce()` | Reduces array values to one value. |

---

## Remember

- Use iteration methods for array loops.
- `map()` returns a new array.
- `filter()` returns matching values.
- `reduce()` returns a single result.
