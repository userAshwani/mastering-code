</div>

---

## Quick Summary

- The window object represents an open window in a web browser.
- All global JavaScript variables, functions, and objects automatically become members of window.
- window.innerHeight and window.innerWidth return the inner viewport dimensions in pixels.
- window.open() opens a new browser window or tab.
- window.close() closes the current browser window.

---

## Key Points

| Feature / Method | Description |
| :--- | :--- |
| **window.innerHeight** | The inner height of the browser viewport in pixels. |
| **window.innerWidth** | The inner width of the browser viewport in pixels. |
| **window.open()** | Opens a new browser window or tab. |
| **window.close()** | Closes the current browser window. |

## Remember

- The window object is supported by all modern browsers automatically.
- Global functions like alert() or setTimeout() are methods of the window object.
- window.document refers to the DOM document object.
- Viewport size does not include browser toolbars or scrollbars.
