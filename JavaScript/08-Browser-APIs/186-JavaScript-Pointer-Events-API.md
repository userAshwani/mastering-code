## Quick Summary

- Pointer events handle mouse, touch screen, and digital pen inputs uniformly.
- pointerdown fires when a pointer device becomes active on an element.
- pointerup fires when a pointer device is released from an element.
- pointermove fires when a pointer changes coordinate position.
- pointerType property identifies whether input device is "mouse", "pen", or "touch".

---

## Key Points

| Feature / Method | Description |
| :--- | :--- |
| **pointerdown** | Fires when pointer contacts element area. |
| **pointerup** | Fires when pointer releases contact. |
| **pointermove** | Fires as pointer moves across coordinate space. |
| **pointerType** | String identifying input type ("mouse", "pen", "touch"). |

## Remember

- Pointer Events eliminate the need to handle mouse and touch events separately.
- pointerId uniquely identifies each active touch or stylus pointer.
- setPointerCapture() redirects future pointer events to a specific element.
- Supported natively by modern desktop and mobile web browsers.
