## Quick Summary

- The document object is the root owner of all HTML elements on a web page.
- document.title gets or sets the title of the document shown in browser tabs.
- document.body provides direct access to the <body> element.
- document.forms returns a collection of all <form> elements in the page.
- document.images returns a collection of all <img> elements on the page.

---

## Key Points

| Feature / Method | Description |
| :--- | :--- |
| **document.body** | Refers to the HTML <body> element. |
| **document.title** | Gets or sets the page title. |
| **document.forms** | HTMLCollection of all form elements on the page. |
| **document.cookie** | Gets or sets cookies associated with the current document. |

## Remember

- The document object is part of the window object (window.document).
- Built-in collections like document.forms or document.links allow fast element lookups.
- document.head provides access to the document <head> section.
- Modifying document.title instantly updates the browser tab caption.
