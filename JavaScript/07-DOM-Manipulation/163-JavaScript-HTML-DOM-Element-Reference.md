## Quick Summary

- HTML element objects inherit properties and methods from the Element interface.
- children returns an HTMLCollection of all child elements.
- parentElement returns the parent node of the current element.
- attributes returns a NamedNodeMap of an element declared attributes.
- focus() and blur() set or remove keyboard focus from form elements.

---

## Key Points

| Feature / Method | Description |
| :--- | :--- |
| **children** | Collection of element child nodes excluding text nodes. |
| **parentElement** | Returns the parent element node. |
| **hasAttribute()** | Returns true if an element has a specified attribute. |
| **removeAttribute()** | Removes a specified attribute from an element. |

## Remember

- children returns child elements, while childNodes includes text and comment nodes.
- focus() sets input focus programmatically on form controls.
- hasAttribute() checks for attribute existence before retrieving values.
- All HTML elements share common DOM Element properties and methods.
