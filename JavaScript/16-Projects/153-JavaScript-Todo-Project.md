## Quick Summary

- A todo app stores tasks.
- Users can add new items.
- Tasks are displayed in a list.
- JavaScript updates the page.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| Input | Receives task text. |
| Add Button | Creates a task. |
| List | Displays tasks. |
| DOM Update | Adds task to the page. |

---
