## Quick Summary

- Validation checks input values.
- Required fields should not be empty.
- Invalid input can show a message.
- JavaScript can stop form submission.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| Input | User-entered value. |
| Validation | Checks the value. |
| Error Message | Shows what is wrong. |
| Submit | Can be allowed or stopped. |

## Remember

- Check input before submitting.
- Show simple error messages.
- Prevent empty required values.
- Validate values the user enters.
