## Quick Summary

- Event listeners wait for actions.
- Click events are common.
- `addEventListener()` attaches a listener.
- The callback runs when the event occurs.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| Element | Receives the listener. |
| Event Type | Example: `click`. |
| Callback | Function that runs. |
| Listener | Connects event to code. |

---

## Simple Example

<details open>
<summary><strong>💻 Click to Hide/Show Code Example</strong></summary>
<br>

```javascript
document.getElementById("demo").addEventListener("click", function() {
  console.log("Clicked");
});
```
</details>

---

## Remember

- Use `addEventListener()` for events.
- Pass the event name as text.
- Pass a function to run.
- Listeners connect user actions to code.
