## Quick Summary

- A counter stores a numeric value.
- Buttons can increase or decrease the value.
- JavaScript updates the displayed number.
- Event handlers respond to clicks.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| Count | Current number value. |
| Button | Triggers a change. |
| Event | Click action. |
| Display | Shows the updated count. |

---

## Simple Example

<details open>
<summary><strong>💻 Click to Hide/Show Code Example</strong></summary>
<br>

```javascript
let count = 0;
count++;
document.getElementById("count").innerHTML = count;
```
</details>

---

## Remember

- Store the count in a variable.
- Update the value on click.
- Write the new value to the page.
- Keep the displayed value in sync.
