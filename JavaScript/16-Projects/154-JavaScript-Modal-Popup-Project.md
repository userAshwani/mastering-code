## Quick Summary

- A modal is hidden or visible.
- Buttons can open and close it.
- JavaScript changes display styles.
- The modal appears above page content.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| Modal | Popup content area. |
| Open Button | Shows the modal. |
| Close Button | Hides the modal. |
| Style Change | Controls visibility. |

---

## Simple Example

<details open>
<summary><strong>💻 Click to Hide/Show Code Example</strong></summary>
<br>

```javascript
document.getElementById("modal").style.display = "block";
```
</details>

---

## Remember

- Use JavaScript to show the modal.
- Use JavaScript to hide the modal.
- Connect buttons with events.
- Keep modal state clear.
