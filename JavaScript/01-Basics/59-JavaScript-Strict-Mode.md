---

## Quick Summary

- Strict mode is declared with `"use strict"`.
- It can be used for a script or a function.
- It helps catch unsafe actions.
- Undeclared variables are not allowed.

---

## Key Points

| Rule | Meaning |
| :--- | :--- |
| `"use strict"` | Turns on strict mode. |
| Script Level | Applies to the whole script. |
| Function Level | Applies only inside that function. |
| Undeclared Variables | Cause errors in strict mode. |

---

## Simple Example

<details open>
<summary><strong>💻 Click to Hide/Show Code Example</strong></summary>
<br>

```javascript
"use strict";
x = 3.14;
```
</details>

---

## Remember

- Place `"use strict"` at the beginning.
- Strict mode changes previously accepted mistakes into errors.
- It applies only where it is declared.
- It is a literal expression.
