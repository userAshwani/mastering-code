## Quick Summary

- A code block is written inside `{ }`.
- Blocks group statements together.
- `let` and `const` can be limited to a block.
- `var` is not limited to block scope.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| `{ }` | Creates a code block. |
| Block Scope | Keeps `let` and `const` inside the block. |
| `let` | Cannot be accessed outside its block. |
| `var` | Can be accessed outside the block. |

---

## Simple Example

<details open>


</details>

---

## Remember

- Blocks help group related statements.
- `let` and `const` respect block scope.
- `var` does not work the same way.
- Use blocks to keep variables limited.
