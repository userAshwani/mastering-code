## Quick Summary

- Patterns describe text to find.
- Patterns can include character sets.
- Patterns can include metacharacters.
- Patterns can include quantifiers.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| Literal | Exact text. |
| Character Set | Allowed characters. |
| Quantifier | Repetition. |
| Flag | Matching behavior. |

---

## Simple Example

<details open>
<summary><strong>💻 Click to Hide/Show Code Example</strong></summary>
<br>

```javascript
let text = "The rain in Spain";
let result = text.match(/ain/g);
```
</details>

---

## Remember

- Build patterns from smaller parts.
- Use flags when needed.
- Use quantifiers for repeats.
- Test patterns with sample text.
