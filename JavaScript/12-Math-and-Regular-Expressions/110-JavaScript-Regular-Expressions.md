---

## Quick Summary

- A regular expression is a search pattern.
- Patterns are used with strings.
- They can search, replace, and match text.
- Regular expressions can use flags.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| Pattern | Text-matching rule. |
| Flag | Changes search behavior. |
| `search()` | Searches a string. |
| `replace()` | Replaces matched text. |

---

---

## Remember

- Use regex for text matching.
- Patterns can be written between slashes.
- Flags modify matching.
- Regex works with string methods.
