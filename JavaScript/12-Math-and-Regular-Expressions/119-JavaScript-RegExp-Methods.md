## Quick Summary

- `test()` checks if a pattern matches.
- `exec()` searches for a match.
- String methods can use regex.
- Regex methods work with text.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| `test()` | Returns true or false. |
| `exec()` | Returns match information. |
| `match()` | String regex match. |
| `replace()` | Replaces matched text. |

## Remember

- Use `test()` for checks.
- Use `exec()` for details.
- String methods can accept regex.
- Regex methods depend on the pattern.
