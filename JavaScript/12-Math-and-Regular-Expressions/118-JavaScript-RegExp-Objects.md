**RegExp objects represent regular expression patterns.**

</div>

---

## Quick Summary

- RegExp objects store patterns.
- Regex can be created with literals.
- Regex can be created with `RegExp()`.
- RegExp objects have methods.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| `/pattern/` | Regex literal. |
| `new RegExp()` | Regex constructor. |
| `test()` | Tests a match. |
| `exec()` | Returns match details. |

---

## Simple Example

<details open>
<summary><strong>💻 Click to Hide/Show Code Example</strong></summary>
<br>

```javascript
let pattern = /e/;
let result = pattern.test("The best things in life are free!");
```
</details>

---

## Remember

- Regex literals are common.
- Use `test()` for true or false.
- Use `exec()` for details.
- RegExp objects store search patterns.
