## Quick Summary

- `Math.random()` returns a number from `0` up to `1`.
- The result is always less than `1`.
- Use `Math.floor()` for random integers.
- Scale the value to change the range.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| `Math.random()` | Random decimal. |
| `Math.floor()` | Converts down to integer. |
| Multiply | Expands the range. |
| Add | Shifts the starting value. |

---

## Simple Example

<details open>
<summary><strong>💻 Click to Hide/Show Code Example</strong></summary>
<br>

```javascript
let x = Math.floor(Math.random() * 10);
```
</details>

---

## Remember

- Random starts at `0`.
- Random does not include `1`.
- Use `floor()` for whole numbers.
- Multiply for larger ranges.
