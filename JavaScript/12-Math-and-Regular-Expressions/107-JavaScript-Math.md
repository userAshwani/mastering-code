## Quick Summary

- `Math` is a built-in JavaScript object.
- It has rounding, power, root, and random methods.
- It includes constants like `Math.PI`.
- Math is not used with `new`.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| `Math.round()` | Rounds to nearest integer. |
| `Math.ceil()` | Rounds up. |
| `Math.floor()` | Rounds down. |
| `Math.random()` | Returns a random number below `1`. |

## Remember

- Use `Math` directly.
- Do not use `new Math()`.
- Random values are less than `1`.
- Rounding methods return integers.
