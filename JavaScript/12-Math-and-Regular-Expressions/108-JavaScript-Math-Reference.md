## Quick Summary

- Math properties store constants.
- Math methods calculate numeric results.
- Methods can find minimum and maximum values.
- Methods can round and transform numbers.

---

## Key Points

| Feature | Meaning |
| :--- | :--- |
| `Math.PI` | Returns PI. |
| `Math.max()` | Highest value. |
| `Math.min()` | Lowest value. |
| `Math.pow()` | Power value. |

## Remember

- Math properties are read directly.
- Math methods use parentheses.
- Use `max()` and `min()` for comparisons.
- Use Math for numeric work.
