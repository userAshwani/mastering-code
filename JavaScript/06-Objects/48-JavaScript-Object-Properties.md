**Object properties are named values inside JavaScript objects.**

</div>

---

## Quick Summary

- Properties store values in an object.
- Properties can be accessed with dot notation.
- Properties can be accessed with bracket notation.
- Properties can be added, changed, or deleted.

---

## Key Points

| Syntax | Simple Meaning |
| :--- | :--- |
| `object.property` | Dot notation. |
| `object["property"]` | Bracket notation. |
| `object.property = value` | Add or change a property. |
| `delete object.property` | Delete a property. |

---

## Simple Example

<details open>
<summary><strong>💻 Click to Hide/Show Code Example</strong></summary>
<br>

```javascript
const person = {
  firstName: "John",
  lastName: "Doe",
  age: 50
};

console.log(person.firstName);
console.log(person["lastName"]);
```
</details>

---

## Remember

- Properties are object values.
- Dot notation is simple and common.
- Bracket notation can use strings.
- `delete` removes a property.
