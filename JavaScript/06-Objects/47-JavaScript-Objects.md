## Quick Summary

- Objects store data as name-value pairs.
- Object values are called properties.
- Objects can also have methods.
- Object literals use curly braces.

---

## Key Points

| Item | Simple Meaning |
| :--- | :--- |
| Object | A collection of related values. |
| Property | A named value inside an object. |
| Method | A function inside an object. |
| Object literal | An object written with `{}`. |

---

## Simple Example

<details open>
<summary><strong>💻 Click to Hide/Show Code Example</strong></summary>
<br>

```javascript
const car = {
  type: "Fiat",
  model: "500",
  color: "white"
};

console.log(car.type);
```
</details>

---

## Remember

- Objects group related data.
- Properties use `name: value` pairs.
- Use dot notation to read properties.
- Objects can contain functions as methods.
